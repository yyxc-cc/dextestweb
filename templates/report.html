① 编号步骤（点开看：操作 / 数据流向 / 前置条件 / 产出 / 不做会怎样）

  1. Step 1 建产品线 PL-001 → 草稿
    输入编码 PL-001、名称（占位）
    操作产品线模块 → 新建 → 保存
    数据流向工艺员 → 产品线 对象 → 草稿
    前置 / 产出无 / 产品线记录（未启用不可选）
    不做会怎样Step 2 的"产品线"下拉为空
  2. Step 2 建产品 P-001 → 草稿
    输入编码 P-001、名称、单位、分类、产品线
    操作产品管理 → 新建 → 保存
    数据流向工艺员 → 产品 对象 → 草稿（保守假设，待核对）
    前置 / 产出Step 1 完成 / 产品草稿
    不做会怎样产品不出现在任何选择器里
  3. Step 3 提交审核 → 待审
    操作详情页 → 提交审核（或送审）
    数据流向工艺员 → 状态 草稿 → 待审
    前置 / 产出必填齐全 / 待审记录 + 审核任务
    不做会怎样无审批人可审，流程停住
  4. Step 4 审核通过 + 发布 （门槛步）
    操作技术主管审核通过 → 发布/启用
    数据流向审核人 → 待审 → 已发布；发布时间落库
    前置 / 产出审核角色账号 / 已发布产品
    不做会怎样列表查不到、BOM 选不到（最容易被漏的一步）
  5. Step 5 列表/前台可见（可被引用）
    操作打开列表 / 前端门户，核对接口返回
    数据流向已发布 → 列表查询接口读到 → 对外可见
    前置 / 产出Step 4 完成 / 可见性证据（截图 + 接口）
    不做会怎样把"未发布"误判成"创建失败"
  6. Step 6 建 BOM V1.0 → 草稿
    输入父件 P-001、子件物料、用量、版本 V1.0
    操作BOM 模块 → 新建 → 加行 → 保存
    数据流向工艺员 → BOM 对象 → 草稿（引用物料主数据）
    前置 / 产出Step 5 完成、子件已发布 / BOM 草稿
    不做会怎样BOM 列表不出现；工单选不到 BOM
  7. Step 7 BOM 审核 → 待审
    操作提交审核
    数据流向工艺员 → 草稿 → 待审
    前置 / 产出用量 > 0 / 待审 BOM
    不做会怎样无法生效，工单仍用旧版
  8. Step 8 BOM 生效 （门槛步）
    操作审核通过 → 设生效日期
    数据流向审核人 → 待审 → 已生效；写生效日期
    前置 / 产出版本唯一、无冲突生效版本 / 生效 BOM V1.0
    不做会怎样工单取到空 BOM 或旧 BOM
  9. Step 9 工单 WO-001 引用 BOM
    输入产品 P-001、数量（占位）
    操作工单模块 → 新建 → 选产品 → 系统带出 BOM/工艺
    数据流向计划员 → 工单 对象 → 引用 BOM V1.0 + 工艺路线
    前置 / 产出Step 8 完成 / 工单草稿（含 BOM 快照）
    不做会怎样工单建不出，或 BOM 明细为空
